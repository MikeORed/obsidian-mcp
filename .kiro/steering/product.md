# Product Overview

Obsidian MCP Server is a Model Context Protocol (MCP) server that enables AI assistants to interact with Obsidian vaults. It provides comprehensive tools for reading, creating, editing, and managing notes and tags within Obsidian knowledge management systems.

## Core Functionality

- **Note Management**: Create, read, edit, delete, and move notes
- **Directory Operations**: Create directories and organize vault structure
- **Tag Management**: Add, remove, rename tags across notes
- **Search Capabilities**: Full-text search and tag-based filtering
- **Multi-Vault Support**: Manage multiple Obsidian vaults simultaneously

## Target Users

- AI assistants (Claude Desktop, etc.) that need to interact with Obsidian vaults
- Knowledge workers using Obsidian for note-taking and organization
- Developers building AI-powered knowledge management workflows

## Key Features

- **Security-First**: Path validation, rate limiting, and vault isolation
- **Multi-Vault**: Support for up to 10 concurrent vaults with automatic naming
- **Comprehensive API**: 13+ tools covering all essential Obsidian operations
- **Error Handling**: Robust error reporting with actionable messages
- **Standards Compliance**: Full MCP protocol implementation

## Installation Methods

- NPX direct execution (recommended)
- Manual installation for development
- Smithery package manager integration
